# Pokémon Odyssey Companion Guide

A modern, fully interactive companion guide for Pokémon Odyssey — the Pokémon ROM Hack.

Designed as a sleek all-in-one reference tool featuring a full Pokédex, encounter tracker, event Pokémon, TM locations, move tutors, naval encounters, side quests, and more.

Built as a lightweight single-page HTML app that works directly in the browser — no installation required.

---

## ✨ Features

### 📖 Interactive Pokédex
- Searchable Pokédex interface
- Type filtering
- Evolution information
- Ability listings
- Base stats
- Learnsets and Odyssey-specific moves
- Detailed modal popups for every Pokémon

### 🌿 Encounter Tracker
- Area-by-area wild encounters
- Encounter rates and levels
- Catch tracking synced across all locations
- Expand/collapse region menus
- Search by Pokémon or location

### ⭐ Etrian Variants Support
- Highlights all Etrian Variants
- Tracks Pokémon that evolve into Etrian forms
- Integrated references to official variant sheets

### ⚡ Event & Gift Pokémon
- Event encounters
- Trades
- Sidequest rewards
- Progress tracking for obtained Pokémon

### 💀 F.O.E. Encounters
- Boss-style overworld encounters
- Region-based tracking
- Expandable sections

### ⚓ Naval Exploration Guide
- Naval encounter tables
- Expedition encounter groups
- Strata progression support

### 💿 TM & Tutor Reference
- TM locations
- Move tutor locations
- Quick-reference tables

### 📜 Side Quest Guide
- Quest descriptions
- Reward tracking
- Location listings

### 🗺️ Sea Map
- Integrated Odyssey sea map reference

### 💾 Persistent Progress Saving
- Catch progress automatically saves in-browser using local storage
- Progress persists between sessions

### 📱 Responsive Design
- Desktop and mobile friendly
- Optimised for modern browsers
- Works great as a Progressive Web App (PWA)

## 🚀 Getting Started

### Option 1 — Run Locally

1. Download or clone this repository
2. Open `index.html` in your browser

That’s it.

---

### Option 2 — Host on GitHub Pages

1. Upload the files to a GitHub repository
2. Go to:

   `Settings → Pages`

3. Set:
   - **Source:** Deploy from branch
   - **Branch:** `main`

4. Save changes

Your guide will then be publicly accessible through GitHub Pages.
